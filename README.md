# 문화체육관광위원회 의정지원 시스템 (경기도의회 제12대 전반기)

문화체육관광위원회 위원 현황, 소관 자치법규 131건, 소관 실·국과 산하기관,
회기 일정, 행정사무감사 준비자료를 한 사이트에서 보는 도구입니다.

## 여는 방법

- 인터넷 주소: **https://hy9510-collab.github.io/ggassembly-munche/** (휴대폰·다른 PC에서도 열립니다)
- 내 컴퓨터: `실습\문화체육관광위원회\` 폴더에서 `index.html` 을 두 번 누릅니다.
  원본 파일 링크까지 모두 쓰려면 상위 `실습` 폴더에서 로컬 서버를 띄우고
  `http://localhost:3100/문화체육관광위원회/` 로 여는 것이 가장 확실합니다.

> **인터넷 주소에서 빠지는 것**
> 문화체육관광국이 제출한 **상임위 심사용 예산자료(세출 484개 사업 금액)** 는 공개 주소에 올리지 않았습니다.
> 예산 화면은 내 컴퓨터에서 열 때만 나옵니다. `munhwa` 폴더의 예산 원본 파일(PDF·엑셀·한글)도
> 올리지 않았으므로 인터넷 주소에서는 해당 링크가 비활성으로 표시됩니다.

연락처·생년월일·주소 등 개인정보는 넣지 않았습니다.

## 고치는 방법

페이지(HTML)는 껍데기이고 실제 내용은 `data/` 폴더의 JSON 파일에 있습니다.
내용을 바꿀 때는 JSON을 고치면 모든 페이지에 반영됩니다.

| 파일 | 내용 |
| --- | --- |
| `data/committee.json` | 위원 명단, 소관 기관, 과별 현황, 회기 일정, 위원회 권한 |
| `data/ordinances.json` | 소관 자치법규 131건 (과·주제군·母조례·중복 검토) |
| `data/budget.json` | 2026년 본예산(안) *(공개 저장소에서 제외)* |

머리글·메뉴·푸터와 차트·CSV 기능은 `assets/site.js` 의 `shell()` 함수가 넣어 줍니다.
페이지를 새로 추가할 때는 `site.js` 맨 위 `NAV` 배열에 한 줄만 넣으면 메뉴에 나타납니다.

## 깃허브에 올리기

바뀐 내용을 인터넷 주소에 반영하려면 **`깃허브 올리기.bat`** 을 두 번 누릅니다.
예산 자료(`data/budget.json`)는 `.gitignore` 에 들어 있어 실수로 올라가지 않습니다.
